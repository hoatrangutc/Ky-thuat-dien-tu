# Ôn luyện Kỹ thuật điện tử 
- Mở trực tiếp trên máy tính để thử; trên iPhone nên triển khai qua HTTPS.
- Đăng trang lên GitHub Pages: tạo repo, tải `index.html` lên nhánh `main`, vào Settings > Pages > Deploy from a branch > main / (root).
- Kết quả sinh viên lưu trong localStorage của **thiết bị hiện tại**. Bấm In kết quả để lưu lịch sử, xuất CSV và in phiếu.
- Đây là biểu mẫu thông tin sinh viên, **chưa phải đăng nhập xác thực bằng máy chủ**. Để lưu điểm tập trung về giảng viên cần backend/Google Sheets.
